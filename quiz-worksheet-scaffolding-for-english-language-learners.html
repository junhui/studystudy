Worksheet: Scaffolding Instruction for English Language Learners

The use of a K-W-L (know, want to know, learned) chart:

  1. Forces students to have to read and engage in the classroom.

  2. Has no true value in the learning process.

  3. Limits students' abilities to come up with their own independent thoughts and ideas.

  4. Supports the activation of prior knowledge.

Differentiating instruction means:

  1. The use of various instructional strategies in order to support all students.

  2. Making it mandatory for teachers to be able to deliver instruction in multiple languages.

  3. Having a different curriculum just for ELL students.

  4. Using different teachers to teach lessons in the classroom.

Guided practice can be used in:

  1. Any class where English Language Learners and other students need support.

  2. Only in the language arts classroom because English Language Learners are not proficient in the English language.

  3. Only in math class because the concepts are so abstract that students are often confused.

  4. Only when the teacher has time to fit it into her lesson plans.

Students' prior knowledge is:

  1. Information they're taught in the classroom

  2. Subconscious memory

  3. Information they already know and come to class with

  4. The history of the subject they're being taught

Scaffolding instruction allows teachers to:

  1. Track students so that the high level students are in one group and the low level students are in another.

  2. Water down the curriculum so that students can be successful even if it's at a lower level.

  3. Cut out parts of the curriculum determined to be irrelevant.

  4. Break instruction into smaller components so that students can organize information.
